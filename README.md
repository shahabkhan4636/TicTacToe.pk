# 🎮 TicTacToe.pk

**Tic-Tac-Toe vs a smart computer AI** — can you beat it?

## ✨ Features
- 🤖 Unbeatable AI using the **minimax algorithm**
- 😊 Easy mode (AI makes mistakes) + 🤖 Hard mode
- 📊 Score tracking (You / AI / Draws)
- ✨ Winning line highlight
- Pure JavaScript, no libraries
